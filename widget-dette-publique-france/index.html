Pourquoi utiliser ce widget ?

  • 📊 Données officielles certifiées. Le calcul est basé sur les chiffres publiés par l'INSEE (Comptes nationaux T1 2026, 25/06/2026). Pas d'estimation — les chiffres sont les mêmes que ceux utilisés par Eurostat et le FMI.
  • ⚡ Rythme annualisé crédible. Le compteur augmente de 4 832 € par seconde — valeur calculée à partir du déficit public 2025 (152,5 Md€ ÷ 31 536 000 secondes). Ce n'est pas une animation arbitraire : c'est le rythme théorique annualisé du déficit.
  • 🔧 Zéro maintenance. Hébergé et mis à jour sur nos serveurs. Vous n'avez rien à installer, mettre à jour ou surveiller. Il suffit d'intégrer une fois.
  • 📱 Compatible mobile. Le widget s'adapte aux petits écrans. Le format responsive (code ③) s'ajuste automatiquement à la largeur du conteneur.
  • 🎓 Usage pédagogique. Idéal pour les cours de SES, les exposés sur la dette, les articles de vulgarisation. Les données sont sourcées et vérifiables en deux clics.

Méthode de calcul — transparence totale

Le point de départ du compteur est la dette publique au T1 2026 : 3 536,1 milliards d'euros, publiée par l'INSEE le 25 juin 2026. Il s'agit de la dette au sens de Maastricht (dette brute des administrations publiques consolidée).

La vitesse d'augmentation est calculée à partir du déficit public 2025 : 152,5 Md€ (5,1 % du PIB). En divisant par le nombre de secondes dans une année (31 536 000), on obtient 4 832 € par seconde.

Formule :
Vitesse (€/s) = Déficit annuel ÷ secondes/an
= 152 500 000 000 ÷ 31 536 000
= 4 832 €/s
Note méthodologique : Le compteur mesure le déficit public, pas uniquement la dette. En réalité, la dette augmente un peu moins vite que le déficit brut (certaines recettes de privatisation ou opérations financières réduisent légèrement l'augmentation nette). Le compteur est donc une borne haute conservatrice, conforme aux pratiques des horloges de la dette comparables.

Questions fréquentes

Le widget est-il vraiment gratuit ? Y a-t-il des conditions d'utilisation ?

Oui, totalement gratuit, sans inscription, sans limite. Nous hébergeons le widget librement pour favoriser la diffusion de données économiques fiables au grand public. Une attribution (lien vers le-francais-moyen.com) est appréciée, mais pas obligatoire.

Comment intégrer ce widget sur WordPress ?

Dans l'éditeur Gutenberg, ajoutez un bloc "HTML personnalisé" et collez le code iframe. Dans l'éditeur classique, passez en mode HTML et collez le code. Compatible avec tous les thèmes, aucun plugin requis. Si votre hébergeur bloque les iframes tierces, contactez-nous.

Pourquoi Substack ne fonctionne pas avec l'iframe ?

Les clients email (Gmail, Outlook, Apple Mail) bloquent systématiquement les iframes pour des raisons de sécurité. Pour Substack, utilisez plutôt un lien vers /dette/ avec un texte accrocheur, ou intégrez le widget via la fonctionnalité "Embed" de Substack sur votre page web (pas dans le mail envoyé aux abonnés).

Les données sont-elles à jour ?

Le point de départ est les données INSEE T1 2026, publiées le 25/06/2026 : dette = 3 536,1 Md€ (115,6 % du PIB). Le compteur pédagogique est calculé à partir du déficit 2025 (152,5 Md€). Les données sont mises à jour à chaque publication officielle de l'INSEE (environ tous les trimestres).

Puis-je l'intégrer dans un cours de SES ou un exposé scolaire ?

Oui, c'est exactement un des usages prévus. Toutes les données sont issues de l'INSEE et d'Eurostat, citables dans un travail académique. La page /dette/ contient également un simulateur interactif et des graphiques historiques, utiles pour illustrer des cours sur la soutenabilité de la dette.
